# Lovina Ethical Dolphin Tours: Project Context

## Project Mission
To become the #1 ethical booking gateway for independent dolphin captains in Lovina, North Bali. We differentiate through "The Quiet Encounter" (8:00 AM departures) and strict behavioral protocols to out-design and out-SEO mass-market competitors.

## Tech Stack
- **Frontend:** Next.js 15+ (App Router), TypeScript, Tailwind CSS.
- **CMS:** Sanity.io (Headless) for Blogs, Tours, and Instagram Reels.
- **Payments:** Stripe Checkout (accepting USD).
- **Hosting:** Vercel (planned).
- **Automation (Pending):** Make.com -> Wati.io (WhatsApp Dispatch).

## Key Differentiators (The Moat)
1. **Timing:** 8:00 AM starts to avoid the "sunrise mob."
2. **Behavioral Contract:** Engines to neutral within 30m; parallel approach only.
3. **Accountability:** Customer-led captain audits (10% refund for violations).
4. **Content:** High-aesthetic, curated Instagram social proof.
